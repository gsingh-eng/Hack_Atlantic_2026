# Veritas

Hack Atlantic 2026. Two people tell their side of a small money fight. An AI judge hears both and writes a decision.

This is a booth demo. It is not a real court and not legal advice.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## So far

Welcome, queue, booking, setup, and a live courtroom. The judge hears each party on the stand. The written judgment comes next.

## Keys

Copy `.env.example` to `.env` when you add a Gemini key. Do not commit `.env`.
